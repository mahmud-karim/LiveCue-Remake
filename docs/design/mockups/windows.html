LiveCue for Windows: screen mockups

Static mockups of the Windows app in the remake, drawn with the Daylight tokens from the design system. Frames are 1240 x 660 CSS px (the default window size); the last one is the 960 x 620 minimum. Glass is approximated with translucent fills, borders, gradients and shadows. The real app has no backdrop blur on Windows, by design.

All addresses, ports, paths, ids and model names are placeholders. The QR pattern is random noise and encodes nothing.
