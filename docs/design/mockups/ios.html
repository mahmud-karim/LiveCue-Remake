LiveCue for iPhone: screen mockups

Static mockups of every iPhone screen in the remake, drawn with the Daylight tokens from the design system. Each frame is 393 x 852 CSS px. Glass is approximated with translucent fills, borders, gradients, shadows and backdrop-filter; the real app uses native Liquid Glass for the floating controls and bars.

All names, addresses, prices and model ids are placeholders. The QR pattern is random noise and encodes nothing.
