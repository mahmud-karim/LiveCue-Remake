# LiveCue Remake

A from-scratch remake of LiveCue: a personal iPhone conversation assistant with on-device speech-to-text and a private Windows relay, redesigned with a liquid glass interface on both iPhone and Windows.

This repository is under active construction. The functional spec lives in [docs/spec](docs/spec), and build instructions will land here as each part is completed.

## Layout

| Path | What it is |
| --- | --- |
| `ios/` | iPhone app (SwiftUI) |
| `relay/` | Private relay that runs on the Windows PC |
| `windows/` | Windows desktop app |
| `docs/` | Spec, architecture and design notes |
